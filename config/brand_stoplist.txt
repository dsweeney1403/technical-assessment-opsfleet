# Build config/brand_stoplist.txt: brand names the leak scan skips (D1.16).
#
# A brand is skipped when it would match ordinary text in an answer:
# - 2 characters or fewer, or no letters at all (numbers like 686 or 1826)
# - a single common English word (lowercase entries in /usr/share/dict/words that are not also
#   proper nouns, so Canada and Jordan stay in), month or weekday
# - a few several-word brands that read like analysis labels ("Age Group", "East Coast").
#   Other several-word brands stay in: matching is case-sensitive, so a title-case
#   phrase like "True Religion" almost only appears when it means the brand.
# - all-caps single words stay in ("GUESS", "PUMA") for the same reason
# - equal to, or a whole phrase inside, a data value (category, department, status,
#   traffic source, country, state, city), e.g. "Carolina" in "North Carolina"
